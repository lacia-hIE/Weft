# 微信、飞书、QQ 功能对齐清单

对照 [xmanrui/dsh-im 5.7.0](https://github.com/xmanrui/dsh-im/tree/e278ac7da82384e6e21d907c606db6545fdc1d1e)，固定提交 `e278ac7da82384e6e21d907c606db6545fdc1d1e`。范围仅为现有三个渠道；不扩展其他渠道。

这里记录的是工作区实现状态，**不表示已经发布、通过远端 CI 或合并到 main**。当前版本不能称为原项目的完整移植。标为「部分」的项目不能按已完成验收；原项目后续变化也不能自动算作本清单已覆盖。

## 机器人与接入

| 能力 | 本地实现状态 | 差距与验收要求 |
| --- | --- | --- |

| 同渠道多个机器人 | 缺失 | 当前每渠道一个；须按 botId 隔离凭据、连接、配置、去重、会话路由及移除操作，并迁移现有账号 |
| 微信扫码、长轮询、暂停恢复 | 已实现 | 模拟平台回归；真实微信账号仍需验收 |
| QQ 扫码创建、长连接、手动凭据 | 已实现 | 模拟平台回归；真实 QQ 账号仍需验收 |
| 飞书／Lark 扫码创建、长连接、手动凭据 | 部分 | 基础文本权限与连接已实现；增量补全权限、卡片回调及 /repair 缺失 |
| 检查连接并向最近私聊发送测试消息 | 部分 | 目前检查凭据／连接；尚无最近私聊测试消息与路由诊断 |

## 每机器人设置

| 能力 | 本地实现状态 | 差距与验收要求 |
| --- | --- | --- |
| 别名、工作区、Agent Preset | 已实现 | 工作区经宿主 `uiWorkspace` 浏览、输入路径或新建文件夹后选择；Agent Preset 从宿主 `remote.agentPresets` 目录下拉选择，可跟随默认，失效预设保留并标注；宿主缺少对应服务时退回文本框。仅影响新会话；Weft 默认路径是 /workspace |
| 模型、推理强度 | 已实现 | 从宿主可用目录读取提供方、模型及档位，只影响新会话；原生选择接口不改写宿主默认模型；不可用选择明确失败且保留原会话 |
| 通用：排队／插话、/steer | 部分 | 使用原生 Session inbox 的 queue／steer，并检查命令权限；已验证繁忙任务中 next-step／next-turn 的权限边界；排队及插话确认提示仍待补 |
| 私聊／群聊访问模式与用户命令权限 | 已实现 | 独立开放／白名单、默认命令权限、逐用户覆盖；旧 allowedSenders 在显式编辑前保留，扫码绑定者保留访问权限；复用原项目策略判断 |
| 上下文增强 | 已实现 | 私聊／群聊独立开关、9 个来源字段、8000 字增强提示词；默认关闭，仅注入所选且实际提供的字段；复用原项目序列化与转义 |
| 主动投递 | 缺失 | 目标选择／手填、保存、测试、复制参数、HTTP 和插件入口均待移植 |
| 当前私聊会话双向同步 | 部分 | 经宿主回合通知（`weftSessionEvents`）回推：定时任务结果发到私聊和群聊，「定时任务和 Web 回合」时 Web 回合连同提问发到私聊；跟随 `/new` 切换订阅，不重复 IM 自己的回合。IM 消息同步到 Web 端的展示、CLI 来源与会话切换命令待补 |
| 绑定 DS Bot | 缺失 | 原项目可绑定同宿主 ds-bot 插件的既有私聊，并校验已启用、可写及绑定冲突；Weft 尚未提供对应集成 |

## 实施与验收顺序

1. **共享设置与数据兼容**：访问控制、上下文增强、消息处理方式；保存、重载、旧配置迁移，以及实际消息生效的回归。
2. **多机器人与宿主目录**：稳定 botId 和数据迁移先于多卡片 UI；接入模型／强度／Preset／目录选择，验证配置不串号、不改变已有 Session 或宿主默认模型。
3. **投递与飞书交互**：话题路由、完整命令、权限补全、过程展示、主动投递与双向同步。
4. **附件与可选能力**：文件／图片、群记录、清理设置及语音，补齐宿主文件和工具接口。
5. **完整 UI 与故障验收**：每项必须同时具备界面、持久化、后端行为和回归；三个真实平台分别验收，不能把模拟平台结果写成真实平台验证。

前端可复用原项目组件、样式和纯逻辑；依赖 Node SDK、磁盘、ffmpeg 或本机服务的后端通过 Weft 的原生服务适配。不能只复制设置名称，也不能把静态开关列为完成。
