# Weft 0.2.2-rc.4

## English

Weft moves to upstream **DSH 0.2.2-rc.4** and takes the same version number. Weft 0.2.2-rc.3 was not released separately, so this release also includes its changes. Neither DSH 0.2.2-rc.3 nor rc.4 changes a Session, persistence, tool or preset contract, so this is an in-place upgrade from Weft 0.2.2-rc.2 or 0.2.2-rc.1.

- The native runtime, official Web client, Remote ABI and official profile are built from the pinned 0.2.2-rc.4 source.
- **DeepSeek content refusals** are reported as such. When DeepSeek ends a reply with a `refusal` under its content safety review, the turn fails with `CONTENT_REFUSED` and the message "Model provider refused to answer under its content safety review". Previously the same response failed as an invalid stream (`MALFORMED_RESPONSE`). The refusal is not retried, the Web client withdraws the streamed reply, and the Session keeps it as a failed attempt outside the model history. Upstream adds the provider's explanation (for example, which images were blocked) to the error; Weft does not store or show provider-supplied failure text, so the message stays fixed.
- **Session log export** follows upstream: an attachment whose stored object is missing no longer fails the whole export. The archive skips it and lists it in `attachments-missing.txt`.
- The sidebar's New-session row and the workspace picker follow the upstream redesign. The workspace picker is now a reusable component that the original directory chooser also fills; Weft's browse-and-create flow is unchanged.
- **DeepSeek chat import is not offered yet.** Upstream DSH 0.2.2-rc.3 added it as an experimental optional bundle that imports a `deepseek_data-*.zip` export from the DeepSeek website as Sessions. It buffers an export of up to 512 MiB in memory and writes many Sessions through one Host-wide Session store. Weft keeps each Session in its own Durable Object, and a Worker has 128 MB of memory, so the bundle needs its own adapter first. It is not listed on the Plugins page.
- Local connector `0.5.2` accepts DSH 0.2.2-rc.3 and 0.2.2-rc.4.

### Compatibility and deployment

Targets upstream **DSH 0.2.2-rc.4** (commit `3f321d32bfe382212a8ed8785c1d47a5a300aa23`). Sessions created under DSH 0.2.2-rc.3, rc.2 or rc.1 keep their revision and keep running. Official presets and the environment's own presets are republished for rc.4 with their rows unchanged; upstream's preset definitions did not change. Sessions created under DSH 0.2.1 still do not run.

The local connector is independently versioned at **0.5.2** and supports native Hosts **0.2.2-rc.1 through 0.2.2-rc.4** (Node 24.9 or newer). Connector 0.5.1 accepts rc.1 and rc.2 only: upgrade the connector before upgrading local DSH. Existing pairing files are kept.

No dependency changes. The workspace container and plugin builder image tags change because the pinned commit changed. Publish both images from the CI run of this exact commit before deploying the Worker. This release adds no database migration or data reset.

## 简体中文

Weft 升级到上游 **DSH 0.2.2-rc.4**，并采用相同的版本号。Weft 0.2.2-rc.3 没有单独发布，本版本一并包含其变化。DSH 0.2.2-rc.3 与 rc.4 均未改动会话、持久化、工具或预设契约，因此从 Weft 0.2.2-rc.2 或 0.2.2-rc.1 原地升级即可。

- 原生运行时、官方 Web 客户端、Remote ABI 与官方 profile 均由固定的 0.2.2-rc.4 源码构建。
- **DeepSeek 内容拒答**按拒答报告。DeepSeek 因内容安全审查以 `refusal` 结束回复时，本轮以 `CONTENT_REFUSED` 失败，提示 “Model provider refused to answer under its content safety review”；此前同样的响应会被当作无效流（`MALFORMED_RESPONSE`）。拒答不会重试，Web 撤回已流式显示的回复，Session 把它保存为失败的尝试，不进入模型历史。上游会在错误中附带提供方说明（例如哪些图片被拦截）；Weft 不保存也不显示由提供方给出的失败文本，因此提示保持固定。
- **会话日志导出**随上游调整：附件的存储对象缺失时不再使整个导出失败，归档跳过该附件，并在 `attachments-missing.txt` 中列出。
- 侧栏「新会话」行与工作区选择器随上游改版。工作区选择器改为可复用组件，原版目录选择器同样填入；Weft 的浏览与新建目录流程不变。
- **DeepSeek 对话导入暂不提供。** 上游 DSH 0.2.2-rc.3 新增该实验性可选组合包，可把 DeepSeek 官网导出的 `deepseek_data-*.zip` 导入为会话。它在内存中缓存最大 512 MiB 的导出文件，并通过 Host 级的单一会话存储写入多个会话。Weft 的每个会话保存在各自的 Durable Object 中，Worker 内存上限为 128 MB，因此需要先完成专门的适配。插件页不列出该组合包。
- 本地连接插件 `0.5.2` 接受 DSH 0.2.2-rc.3 与 0.2.2-rc.4。

### 兼容与部署

适配上游 **DSH 0.2.2-rc.4**（提交 `3f321d32bfe382212a8ed8785c1d47a5a300aa23`）。DSH 0.2.2-rc.3、rc.2 与 rc.1 时期创建的会话保留其修订并继续运行。官方预设与环境自己的预设以 rc.4 重新发布，行内容不变；上游预设定义没有变化。DSH 0.2.1 时期创建的会话仍不能运行。

本地连接插件独立版本为 **0.5.2**，支持原版 Host **0.2.2-rc.1 至 0.2.2-rc.4**（Node 24.9 及以上）。0.5.1 只接受 rc.1 与 rc.2，升级本机 DSH 前先升级连接插件；已有配对文件保留。

依赖没有变化。固定提交变化使工作区容器与插件构建镜像的标签更新。部署 Worker 前，从本提交通过 CI 的运行中发布两份镜像。本版本不新增数据库迁移，也不重置数据。
