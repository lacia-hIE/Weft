## English

First versioned Weft application release. Weft adapts DeepSeek Harness to Cloudflare while retaining the native agent loop, Web UI, Cordis bundle format and plugin lifecycle.

- Cloud environments with persistent conversations and workspaces, lifecycle controls and configuration/file copying.
- Linux subprocesses, Git and interactive PTYs, alongside Worker shell and recoverable JavaScript tasks.
- Native npm bundle installation with isolated compilation, review and scoped Host execution.
- Workers AI document-to-Markdown extraction and Cloudflare Images attachment processing.
- Local DSH relay through the separately published `@laciaproject/dsh-local-host` connector.
- Faster homepage loading, direct local Host navigation and coordinated plugin refreshes.
- English/Chinese READMEs, contribution templates and a CI-gated release workflow.

### Compatibility and deployment

Targets upstream **DSH 0.2.1-rc.3**. The local connector is independently versioned at **0.2.4** and supports native Hosts **0.2.1-rc.2 / 0.2.1-rc.3**.

This release introduces project versioning and documentation; it adds no database migration, container image change or data reset. Historical v1-to-`harness-v2` deployment upgrades have a separate reset boundary described in the deployment guide. Existing v2 installations retain their data on this update.

Deploy with your own Cloudflare account, domain, Access policy, private resources and verified container images. The official Deploy to Cloudflare button cannot yet initialize the complete multi-Worker deployment. Source archives require a configured build before deployment. Synchronized workspace files remain limited to 256 MiB each; processes and PTYs do not survive container replacement. Port preview support is not included.

## 简体中文

首个带版本 Tag 的 Weft 项目版本。沿用原版 Agent Loop、Web UI、Cordis bundle 格式和插件生命周期，将 DeepSeek Harness 接入 Cloudflare。

- 云端独立环境、持久会话与工作区，支持环境生命周期及配置与文件复制。
- Linux 真实进程、Git 与 PTY，同时提供 Worker shell 和可恢复 JavaScript 任务。
- 原生 npm 插件安装、隔离编译、用户审核与授权 Host 执行。
- Workers AI 文档转 Markdown 与 Cloudflare Images 附件处理。
- 通过独立发布的 `@laciaproject/dsh-local-host` 接入本地 DSH。
- 首页按需加载、直达本地 Host、插件刷新合并与并发协调。
- 中英文 README、贡献模板与 CI 校验后的发版流程。

### 兼容与部署

适配上游 **DSH 0.2.1-rc.3**；本地连接插件独立版本为 **0.2.4**，支持原版 Host **0.2.1-rc.2 / 0.2.1-rc.3**。

本次引入项目版本管理和开源文档，不新增数据库迁移、不更换容器镜像、不重置数据。历史 v1 升级到 `harness-v2` 的重置边界见部署指南；现有 v2 部署正常保留数据。

使用自己的 Cloudflare 账号、域名、Access 策略、私有资源和已验证镜像部署。官方一键部署按钮目前不能完成多 Worker 的全部初始化；源码包需要完整配置后构建。同步工作区单文件仍限制为 256 MiB，容器替换后不恢复进程与 PTY，本版尚不包含端口预览。
