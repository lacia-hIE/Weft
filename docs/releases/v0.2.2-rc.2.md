## English

Weft moves to upstream **DSH 0.2.2-rc.2** and takes the same version number. rc.2 reads 0.2.2-rc.1 Session logs in place, so this is an in-place upgrade from Weft 0.2.2-rc.1.

- The native runtime, official Web client, Remote ABI and official profile are built from the pinned 0.2.2-rc.2 source.
- **Agent Teams is built in.** Upstream moved Agent Teams from the optional `@deepseek-ai/dsh-experimental-agent-team-profile` bundle into the base bundle. Team mode is now a switch in the original conversation menu, saved per root conversation and off by default. When it is on, the agent gets the shared task-board tools (`team_task_create`, `team_task_list`, `team_task_get`, `team_task_update`) and the Team guidance. Teammates are ordinary named subagents running in the same Session object, and messages address them by name. Turning Team mode off removes the tools but keeps the task board.
- **Web search** follows the new upstream default, the DeepSeek Search API, sent to the configured DeepSeek endpoint's `/v1/tools`. Legacy Messages search remains selectable in Web search settings.
- **Office toolkit**: upstream replaced `office-to-pdf` with `office-kit` (render, convert and recalculate) plus `tool-office` and `skill-office`. These need a LibreOffice Container that Weft does not provide yet, so `tool-office` is listed but disabled in the standard and PTC presets. Office/PDF text extraction through Workers AI is unchanged.
- Upstream's settings-driven MCP manager is not mounted; the environment's MCP server settings continue to mount the original MCP client for remote servers.
- Since 0.2.2-rc.1: hibernatable WebSocket feeds for passive browser subscriptions; IM `0.11.0` answers native questions from chats; Superagent `0.4.2` with local task navigation, the original directory chooser and dispatch hints; local connector `0.5.1`.

### Built-in plugins

| Plugin | Version | Changes since 0.2.2-rc.1 |
| --- | --- | --- |
| `@weft/dsh-im` | 0.11.0 | Forwards native questions to the originating chat; numbered, custom and sequential batch answers |
| `@weft/dsh-superagent` | 0.4.2 | Local task Session navigation, the original directory chooser for task roots, advisory dispatch hints; requests the existing connections capability |
| `@laciaproject/dsh-local-host` | 0.5.1 | Accepts DSH 0.2.2-rc.1 and 0.2.2-rc.2; opens completed or stopped Superagent tasks |
| Official Agent Teams | DSH 0.2.2-rc.2 | Built in; per-conversation Team mode replaces the optional bundle |

After deploying, open the bundle review for IM and Superagent and approve the new versions. Superagent 0.4.2 asks for the connections capability.

### Compatibility and deployment

Targets upstream **DSH 0.2.2-rc.2** (commit `ddac96760b6edf8fa0fe17cbdcf0b512f4c12b2c`). Sessions created under 0.2.2-rc.1 keep their revision and keep running. Official presets are republished for rc.2. The environment's own presets are republished after dropping rows of the former Agent Teams bundle (`agent-team`, `tool-agent-team`, `ui-agent-team`). A former Agent Teams bundle selection is removed when the environment opens. Existing Team task boards remain readable. Sessions created under DSH 0.2.1 still do not run.

The local connector is independently versioned at **0.5.1** and supports native Hosts **0.2.2-rc.1 and 0.2.2-rc.2** (Node 24.9 or newer). Connector 0.5.0 accepts rc.1 only: upgrade the connector before upgrading local DSH. Existing pairing files are kept.

The only dependency change shared with upstream is `zod` 4.4.3 → 4.6.6. The workspace container and plugin builder image tags change. Publish both images from the CI run of this exact commit before deploying the Worker. This release adds no database migration or data reset.

## 简体中文

Weft 升级到上游 **DSH 0.2.2-rc.2**，并采用相同的版本号。rc.2 可原地读取 0.2.2-rc.1 的会话日志，因此从 Weft 0.2.2-rc.1 原地升级即可。

- 原生运行时、官方 Web 客户端、Remote ABI 与官方 profile 均由固定的 0.2.2-rc.2 源码构建。
- **Agent Teams 改为内置。** 上游把 Agent Teams 从可选组合包 `@deepseek-ai/dsh-experimental-agent-team-profile` 并入 base bundle。团队模式现在是原版会话菜单中的开关，按根会话保存，默认关闭。开启后 Agent 获得共享任务板工具（`team_task_create`、`team_task_list`、`team_task_get`、`team_task_update`）和团队协作提示。队友就是普通的具名子代理，运行在同一个会话对象内，消息按名称投递。关闭团队模式会移除这些工具，但保留任务板。
- **Web 搜索**采用上游新的默认方式 DeepSeek Search API，请求发往所配置 DeepSeek 端点的 `/v1/tools`。旧版 Messages 搜索仍可在 Web 搜索设置中选择。
- **Office 工具包**：上游以 `office-kit`（渲染、转换与重算）以及 `tool-office`、`skill-office` 取代 `office-to-pdf`。它们需要 Weft 尚未提供的 LibreOffice Container，因此 `tool-office` 在标准与 PTC 预设中列出但停用。经 Workers AI 的 Office/PDF 文本提取不受影响。
- 上游按设置启动的 MCP 管理器不挂载；环境的 MCP 服务器设置继续为远程服务器挂载原版 MCP 客户端。
- 0.2.2-rc.1 之后的新增内容：网页被动订阅改用可休眠 WebSocket；IM `0.11.0` 在聊天中回答原生提问；Superagent `0.4.2` 增加本地任务会话直达、原版目录选择器与派工提示；本地连接插件 `0.5.1`。

### 内置插件

| 插件 | 版本 | 0.2.2-rc.1 以来的变化 |
| --- | --- | --- |
| `@weft/dsh-im` | 0.11.0 | 将原生提问发送到来源聊天，支持编号、自定义文字与多题逐项回答 |
| `@weft/dsh-superagent` | 0.4.2 | 本地任务会话直达、原版任务根目录选择器、派工提示；申请既有的连接授权 |
| `@laciaproject/dsh-local-host` | 0.5.1 | 接受 DSH 0.2.2-rc.1 与 0.2.2-rc.2；可打开已完成或停止的 Superagent 任务 |
| 官方 Agent Teams | DSH 0.2.2-rc.2 | 改为内置；按会话开关的团队模式取代可选组合包 |

部署后在 IM 与 Superagent 的组合包审核中批准新版本；Superagent 0.4.2 会申请连接授权。

### 兼容与部署

适配上游 **DSH 0.2.2-rc.2**（提交 `ddac96760b6edf8fa0fe17cbdcf0b512f4c12b2c`）。0.2.2-rc.1 时期创建的会话保留其修订并继续运行。官方预设以 rc.2 重新发布。环境自己的预设去掉原 Agent Teams 组合包的行（`agent-team`、`tool-agent-team`、`ui-agent-team`）后重新发布。环境打开时会移除原有的 Agent Teams 组合包选择，已有的团队任务板仍可读取。DSH 0.2.1 时期创建的会话仍不能运行。

本地连接插件独立版本为 **0.5.1**，支持原版 Host **0.2.2-rc.1 与 0.2.2-rc.2**（Node 24.9 及以上）。0.5.0 只接受 rc.1，升级本机 DSH 前先升级连接插件；已有配对文件保留。

与上游共享的依赖中只有 `zod` 从 4.4.3 升到 4.6.6。工作区容器与插件构建镜像的标签均有变化。部署 Worker 前，从本提交通过 CI 的运行中发布两份镜像。本版本不新增数据库迁移，也不重置数据。
