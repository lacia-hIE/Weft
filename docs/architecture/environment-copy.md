# 环境复制

首页的「复制」创建独立环境，范围固定为配置和持久工作区文件，不提供历史会话复制选项。

## 数据边界

复制环境设置的脱敏 profile、当前预设声明及发布修订号、默认预设、工作区目录登记及顺序、预装官方 bundle 的选择、第三方插件包及其不可变产物、当前客户端插件定义。

第三方插件包和单独发布的客户端插件在副本中保持停用，重新确认后才能启用。凭据引用可以保留，受管密钥和 OAuth 授权不会复制。新环境重新生成 Harness 匿名身份。

文件范围是当前环境的默认 Computer 卷 `/workspace`。保留普通文件、二进制、隐藏文件、Git 数据和文件执行位。不同工作区登记使用这个卷下的目录，文件卷仅复制一次。`.env` 等用户文件随卷复制，不尝试推断文件中的秘密。容器本地依赖和未同步到卷的临时内容不在范围内；容器运行时会先执行现有文件同步。

排除 `/workspace/.weft` 私有附件区、`.dsh/spill`、原始 `profile.yml` 和配置错误文件。目标环境从脱敏配置重新生成自己的 profile，不让源文件覆盖受管密钥边界。会话及子会话、动态插件运行、审批请求、调度、Inbox、上传复用记录、搜索和摘要索引、转换缓存、终端和容器状态均不复制。

## 快照与导入

WorkspaceCopy 是固定版本 Computer/dofs 的存储适配器。在一个同步 SQLite 事务中固化目录、文件模式和文件块字节，不从原始活动文件分页读取。快照之后的修改不会影响已固化字节。符号链接、未加载挂载或缺失字节明确拒绝，不生成悄悄缺文件的副本。

元数据和块按有序游标转移，二进制 Response 避免整卷进入内存，每个块校验 SHA-256。每次至多传输 128 项，后续由新的 Alarm 调用继续，避免大量小文件耗尽单次调用请求额度。配置快照分段存储，避免大预设或包声明组成单个超大 SQLite 行。目标端在本地事务内同时写入块和推进游标，重复请求幂等。目录遍历不经过文件侧栏的列表数量限制。配置和工作区登记在快照期间变化会拒绝本次捕获，允许重试。平台边界见 [Cloudflare DO 限制](https://developers.cloudflare.com/durable-objects/platform/limits/)及[请求额度](https://developers.cloudflare.com/changelog/post/2026-02-11-subrequests-limit/)。

文件全部写入后，通过设置、WorkspaceCommands、官方 bundle 与安装器服务导入配置。第三方产物使用目标环境自己的 R2 路径，源环境卸载不影响副本。副本发布之前不允许打开工作台或调用其文件、执行和会话接口。

这提供已提交文件卷的一致快照，不承诺外部进程或正在运行的应用已经完成自己的业务事务。

## 操作生命周期

`POST /v1/tenants/:tenant/environments/:source/copy` 接收 `{name, requestId}`；requestId 是客户端生成的 UUID，也是目标环境身份。初次请求返回 202，完成后的重复请求返回 200。相同请求 ID 更换来源或名称返回 409。

平台目录状态为 `copying`、`failed`、`ready`，无状态的现有环境按 ready 处理。环境详情和列表提供进度；创建中与失败的环境不能进入工作台。UI 复用 DSH Button、Input、Modal 和主题变量，支持刷新后恢复进度及失败重试。

TenantDO 的 SQLite 保存操作日志，D1 只保存平台环境目录和进度投影。DO Alarm 恢复被中断的复制；失败保留固定快照和目标游标，重试继续原来的副本。成功发布后清理源快照，清理失败单独重试，不把已经可用的副本降为失败。失败的副本仍显示在目录，不隐藏残留数据或自动重新执行任务。

当前这一步补齐复制的创建、失败、重试和完成流程；既有环境的暂停、删除与物理回收仍是独立后续能力。

## 验证

CI 使用真实 Computer 卷验证二进制、中文路径、执行位、超过 5000 个目录项、源快照之后的修改、故障后重启和同请求重试、配置与默认预设、工作区恢复、凭据与历史排除、租户隔离及副本写入独立性。浏览器验证原版组件中的复制和刷新恢复流程。所有构建和运行测试只在 ci 分支执行。
